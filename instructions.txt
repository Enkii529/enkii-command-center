# 🔌 Platform API Wiring Guide — Jay's Social Command Center

## ─── TWITTER / X ───────────────────────────────────────

**What you need:** API Key, API Secret, Access Token, Access Token Secret

**Steps:**
1. Go to **https://developer.twitter.com/en/portal/dashboard**
2. Click **+ Create Project** → name it "Social Command" → use case: "Building tools for myself"
3. Inside the project, click **+ Add App** → give it a name
4. Go to **App Settings → Keys and Tokens**
5. Under **Consumer Keys** → click **Regenerate** → copy `API Key` and `API Key Secret`
6. Under **Authentication Tokens** → click **Generate** under *Access Token and Secret* → copy both
7. Go to **App Settings → User authentication settings** → enable **Read and Write** permissions (REQUIRED for posting)
8. In Social Command → **Platforms tab → X / Twitter → Configure** → paste all 4 keys

**Test it:**
```bash
curl -X POST http://localhost:3559/publish \
  -H "Content-Type: application/json" \
  -d '{"id":999,"content":"Test post from Social Command!","platforms":["twitter"],"brand":"jason","type":"text"}'
```

## ─── META (Facebook + Instagram + Threads) ────────────

**All three share ONE Meta access token — do this once.**

**Steps:**
1. Go to **https://developers.facebook.com/** → click **My Apps → Create App**
2. Choose **Business** type → name it "Social Command"
3. In the app dashboard → **Add Products** → add **Facebook Login** and **Instagram Graph API**
4. Go to **Tools → Graph API Explorer** (https://developers.facebook.com/tools/explorer)
5. Select your app from the dropdown
6. Click **Generate Access Token** — check these permissions:
   - `pages_manage_posts` `pages_read_engagement` `instagram_basic` `instagram_content_publish` `threads_basic` `threads_content_publish`
7. Copy the **User Access Token** (short-lived) — to make it permanent:
8. Go to **https://developers.facebook.com/tools/debug/accesstoken** → paste token → click **Extend Access Token** → copy the long-lived token (~60 days, auto-renewable)

**Get your Page ID (Facebook):**
```
https://graph.facebook.com/v19.0/me/accounts?access_token=YOUR_TOKEN
```
Copy the `id` of your page.

**Get your Instagram User ID:**
```
https://graph.facebook.com/v19.0/me?fields=id,name&access_token=YOUR_TOKEN
```
Then:
```
https://graph.facebook.com/v19.0/YOUR_PAGE_ID?fields=instagram_business_account&access_token=YOUR_TOKEN
```
Copy the `instagram_business_account.id`

**Get your Threads User ID:**
```
https://graph.threads.net/v1.0/me?fields=id,name&access_token=YOUR_TOKEN
```

**In Social Command:** Platforms tab → configure Facebook, Instagram, and Threads — all use the same `META_ACCESS_TOKEN`, then each gets its own ID field.

## ─── LINKEDIN ──────────────────────────────────────────

**Steps:**
1. Go to **https://www.linkedin.com/developers/apps/new**
2. Create an app → associate with your LinkedIn Company Page
3. Under **Auth** tab → add redirect URL: `http://localhost:3559/oauth/linkedin`
4. Under **Products** tab → request **Share on LinkedIn** and **Sign In with LinkedIn** (usually instant approval)
5. Copy your **Client ID** and **Client Secret**

**Get your access token (one-time OAuth flow):**

Add this temporary route to `server.js` to handle the OAuth:

```js
// Temporary — run once to get your token, then remove
import { createServer } from 'http';

app.get('/oauth/linkedin/start', (req, res) => {
  const CLIENT_ID = 'YOUR_CLIENT_ID';
  const REDIRECT = 'http://localhost:3559/oauth/linkedin';
  const scope = 'openid profile email w_member_social';
  res.redirect(`https://www.linkedin.com/oauth/v2/authorization?response_type=code&client_id=${CLIENT_ID}&redirect_uri=${encodeURIComponent(REDIRECT)}&scope=${encodeURIComponent(scope)}`);
});

app.get('/oauth/linkedin', async (req, res) => {
  const { code } = req.query;
  const r = await fetch('https://www.linkedin.com/oauth/v2/accessToken', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({ grant_type: 'authorization_code', code, redirect_uri: 'http://localhost:3559/oauth/linkedin', client_id: 'YOUR_CLIENT_ID', client_secret: 'YOUR_CLIENT_SECRET' })
  });
  const data = await r.json();
  res.json(data); // Copy the access_token from this response
});
```

Visit `http://localhost:3559/oauth/linkedin/start` → authorize → copy the `access_token` from the JSON response.

**Get your Person URN:**
```
https://api.linkedin.com/v2/userinfo
Authorization: Bearer YOUR_TOKEN
```
Copy the `sub` field — that's your Person URN.

**In Social Command:** Platforms tab → LinkedIn → paste `LINKEDIN_ACCESS_TOKEN` and `LINKEDIN_PERSON_URN`

## ─── TELEGRAM ──────────────────────────────────────────

**Easiest platform — 5 minutes total.**

**Steps:**
1. Open Telegram → search for **@BotFather**
2. Send `/newbot` → follow prompts → name it "Oracle Command" or similar
3. Copy the **bot token** it gives you (format: `1234567890:ABCdef...`)
4. Create your channel (e.g. @OracleStrategy) or use existing one
5. Add your bot as an **Administrator** to the channel (this is required for it to post)
6. Get your Channel ID:
   - Send a message to your channel
   - Visit: `https://api.telegram.org/botYOUR_TOKEN/getUpdates`
   - Find `"chat":{"id":` in the response — channel IDs start with `-100`

**In Social Command:** Platforms → Telegram → paste `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHANNEL_ID` (include the `-100` prefix)

**Test immediately:**
```bash
curl "https://api.telegram.org/botYOUR_TOKEN/sendMessage?chat_id=YOUR_CHANNEL_ID&text=Social+Command+is+live"
```

## ─── TIKTOK ────────────────────────────────────────────

**Note:** TikTok requires video files — text-only posts aren't supported on their Content Posting API. The system will hold your caption ready; you'll pair it with video upload when ready.

**Steps:**
1. Go to **https://developers.tiktok.com/** → Login → **My Apps → Create App**
2. App type: **Web** → fill details
3. Under **Products** → enable **Content Posting API**
4. Add redirect URI: `http://localhost:3559/oauth/tiktok`
5. Copy `Client Key` and `Client Secret`
6. For access token — TikTok uses OAuth 2.0 similar to LinkedIn above. Add the same pattern of OAuth routes to `server.js` using TikTok's auth endpoints at `https://www.tiktok.com/v2/auth/authorize/`

**In Social Command:** Platforms → TikTok → paste keys once you complete OAuth

## ─── YOUTUBE ───────────────────────────────────────────

**Note:** Like TikTok, YouTube requires an actual video file to upload. The system stores your description/metadata and publishes when you provide a video.

**Steps:**
1. Go to **https://console.cloud.google.com/**
2. Create a new project → **Enable APIs** → search and enable **YouTube Data API v3**
3. Go to **Credentials → Create Credentials → OAuth 2.0 Client ID**
4. Application type: **Web Application**
5. Authorized redirect URIs: `http://localhost:3559/oauth/youtube`
6. Copy `Client ID` and `Client Secret`
7. Add OAuth route to `server.js` using Google's OAuth endpoints — scopes needed: `https://www.googleapis.com/auth/youtube.upload`
8. Complete OAuth flow → get refresh token (unlike access tokens, refresh tokens don't expire)

**In Social Command:** Platforms → YouTube → paste credentials
