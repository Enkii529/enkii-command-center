# Portal Page Map

## 1. Home

Widgets:
- summary cards from `/summary`
- high-priority open tasks
- tasks due today
- content items not published
- new documents awaiting triage
- recent trades

## 2. Inbox / Triage

Widgets:
- document queue table
- summary/notes side panel
- action buttons:
  - create task
  - attach to venture
  - mark as archived
  - mark as needs research

## 3. Tasks

Widgets:
- task table
- create task form
- quick edit modal
- filters by venture, project, priority, due date, status

## 4. Crypto HQ

Widgets:
- recent trades table
- positions table
- signals table
- journal panel
- allocation card section

## 5. Content Pipeline

Widgets:
- kanban by stage
- quick add idea form
- content performance table
- venture/platform filters

## 6. AI Lab

Widgets:
- model inventory table
- operator run form
- agent run history
- tool call audit log

## 7. Ops

Widgets:
- embedded Grafana panels
- failed jobs table
- recent API health checks
- last agent failures
